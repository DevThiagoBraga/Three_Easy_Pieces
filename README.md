## 📖 Sobre

Este repositório reúne meus estudos do livro **Operating Systems: Three Easy Pieces (OSTEP)**, uma das principais referências mundiais para o estudo de Sistemas Operacionais.

Aqui você encontrará:

- 📚 Resumos dos capítulos
- 💻 Implementações em C
- 🧠 Exercícios resolvidos
- 📝 Anotações pessoais
- 🔬 Experimentos realizados no Linux
- 📂 Projetos desenvolvidos durante a leitura

O objetivo é documentar minha evolução durante a graduação em **Ciência da Computação**, consolidando conhecimentos fundamentais sobre Sistemas Operacionais.

# 🎯 Objetivos

- Estudar profundamente Sistemas Operacionais
- Aprender programação de baixo nível em C
- Desenvolver raciocínio sobre concorrência
- Compreender gerenciamento de memória
- Estudar virtualização
- Dominar escalonamento de processos
- Aprender sincronização entre processos e threads
- Criar uma base sólida para desenvolvimento de software

# 🚀 Como Executar os Exemplos

Clone o repositório

```bash
git clone https://github.com/DevThiagoBraga/three-easy-pieces.git
```

Entre na pasta

```bash
cd three-easy-pieces
```

Compile um exemplo

```bash
gcc exemplo.c -o exemplo
```

Execute

```bash
./exemplo
```
